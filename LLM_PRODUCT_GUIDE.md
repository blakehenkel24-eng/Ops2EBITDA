## Executive Summary

Ops2EBITDA is a private equity operations knowledge platform with two layers:

1. A free knowledge base that teaches how PE value creation works.
2. A paid asset library that helps users do the work.

The paid business is organized into three main product lines:

1. Excel Models
2. AI Project Kits
3. Skill Packages

There are also bundle-level offers built on top of those three lines.

The most important thing for an LLM to understand is this:

- the knowledge base is the trust-building free layer
- the paid layer is the monetized execution layer
- the paid layer is not one vague “course” or “membership”
- it is a catalog of specific operating assets

---

## What The Product Is

Ops2EBITDA started as a static, curated private equity operations reference. Its purpose is to help users think more like an operating partner, value creation lead, or strong PE operations consultant.

It focuses on:

- PE fundamentals
- value creation logic
- industry intelligence
- KPI interpretation
- operating playbooks
- cross-linked operating reasoning from issue -> action -> KPI -> EBITDA / cash flow / valuation

The broader business now extends beyond free educational content. The paid side is intended to sell practical operating assets that save users time and improve the quality of their work.

---

## What The Product Is Not

This product is not supposed to be interpreted as:

- a generic AI chatbot
- a general business education site
- a beginner learning app
- a SaaS dashboard with complicated subscriptions

- a broad consulting services marketplace

It is better understood as:

- a PE operations knowledge base

## Offer Taxonomy In Plain English

### Excel Models

These are premium analytical spreadsheets for PE value creation work.

They are used when structured modeling, scenario analysis, segmentation, or quantified value capture matters.

### AI Project Kits

These are ready-to-build AI workspace packages for recurring PE operating workflows.

They are used when the product is more about instructions, prompting, workflow setup, and reusable AI-assisted working methods than about spreadsheet calculation.

### Skill Packages

These are reusable markdown-based skills that users can upload into AI tools or agent systems.

They are used when the value is not a whole AI workspace, but instead a portable set of reusable instruction assets that improve a specific class of outputs.

### Bundles

These are grouped purchases that combine multiple products for a clearer buying path and a stronger value proposition.

## Product Line 1: Excel Models

### Definition

Excel Models are complex analytical workbooks for PE value creation workstreams where modeling creates real value.

These are not generic spreadsheet templates. They are supposed to feel like real analytical tools a PE operator, consultant, or analyst would actually want to use.

### Job To Be Done

Excel Models should help users:

- quantify EBITDA impact
- quantify cash flow impact
- size enterprise value impact
- run scenarios
- segment messy data
- validate value creation opportunities
- create decision-ready analysis

### Exact Excel Model Offers

The repo contains six named Excel model offers:

1. Pricing Waterfall & Margin Leakage Model
2. Procurement Spend Cube & Savings Tracker
3. Working Capital & Cash Conversion Model
4. Sales Productivity & Pipeline Coverage Model
5. Customer Retention / NRR Cohort Model
6. Add-On Synergy & Integration Value Capture Model

### What Each Excel Model Is For

#### 1. Pricing Waterfall & Margin Leakage Model

Purpose: diagnose discounting, pocket price leakage, customer/SKU margin dispersion, and pricing upside.

Core outputs:

- price waterfall
- margin bands
- discount leakage analysis
- price increase scenarios
- EBITDA bridge

#### 2. Procurement Spend Cube & Savings Tracker

Purpose: analyze third-party spend, vendor consolidation opportunities, maverick spend, and savings capture.

Core outputs:

- spend cube
- vendor/category/site cuts
- addressable spend view
- savings pipeline
- EBITDA validation

#### 3. Working Capital & Cash Conversion Model

Purpose: quantify cash trapped in AR, AP, and inventory.

Core outputs:

- DSO / DPO / DIO bridge
- cash release scenarios
- AR aging impact
- inventory turns analysis
- cash conversion cycle dashboard

#### 4. Sales Productivity & Pipeline Coverage Model

Purpose: diagnose sales productivity, pipeline quality, quota attainment, and capacity gaps.

Core outputs:

- pipeline coverage analysis
- stage conversion analysis
- rep productivity analysis
- quota gap analysis
- bookings forecast

#### 5. Customer Retention / NRR Cohort Model

Purpose: analyze churn, retention, expansion, contraction, and renewal risk.

Core outputs:

- cohort retention views
- GRR / NRR bridge
- logo churn analysis
- expansion/contraction analysis
- churn reason waterfall

#### 6. Add-On Synergy & Integration Value Capture Model

Purpose: track cost, revenue, procurement, G&A, and systems synergies after an add-on acquisition.

Core outputs:

- synergy tracker
- integration milestones
- run-rate EBITDA bridge
- value capture dashboard

### Important Clarification

Excel Models are one product line. Each of the six named models above is an individual product within that line.

## Pricing And Catalog Clarification

This is the section most likely to prevent LLM confusion.

There are two different pricing/catalog lenses in the repo:

### Lens 1: Simplified Pricing Sheet

`Marketing/Offerings/Pricing.md` lists these named offers and prices:

1. Single Excel Model — $99
2. Single AI Project Kit — $49
3. Single Skill Package — $39
4. Core Model Bundle — $399
5. AI Project Library — $299
6. Skill Package Library — $179
7. Full Ops2EBITDA Toolkit — $699

This appears to be the cleaner, more compact pricing surface.

### Lens 2: Strategic Offering Guide

The broader product offering guide describes:

- individual products within each line
- bundle strategy
- suggested pricing ranges
- additional named bundles such as:
  - Daily Operator AI Bundle
  - Analyst Acceleration Bundle
  - Diligence-to-Execution Bundle

### How To Reconcile These

An LLM should not assume these two files are contradictory. They appear to operate at different levels:

- `Pricing.md` looks like the simplified current pricing sheet
- `Ops2EBITDA Product Offering Guide.md` looks like the fuller strategic catalog and roadmap

### Best Interpretation

Use this interpretation unless a newer source overrides it:

- current core sellable categories: Single Excel Model, Single AI Project Kit, Single Skill Package
- current higher-level priced group offers: Core Model Bundle, AI Project Library, Skill Package Library, Full Ops2EBITDA Toolkit
- additional named bundles in strategy/roadmap: Daily Operator AI Bundle, Analyst Acceleration Bundle, Diligence-to-Execution Bundle

### Important Distinction

`AI Project Library` and `Skill Package Library` are explicitly priced in `Pricing.md`.

`Daily Operator AI Bundle`, `Analyst Acceleration Bundle`, and `Diligence-to-Execution Bundle` are explicitly named in the strategy guide.

Therefore, an LLM should not collapse all of these into one flat bundle list without noting that some appear to be current price-sheet offers and some appear to be more strategic or roadmap-oriented bundle concepts.
