# KPI High-Depth Content Standard

**Status:** Draft
**Date:** 2024-05-22

## Goal
Transform 18 thin KPI articles into high-depth, "Senior Operating Partner" level briefings that provide immediate tactical value and professional credibility.

## The Standard

### 1. Section Structure (Exactly 5)
Every KPI JSON file must contain exactly 5 sections with the following themes:
- **Strategic Context & Value Driver:** Why the board and GP care about this metric.
- **Operational Levers & Benchmarking:** How to improve it and what "best-in-class" looks like.
- **Math & Unit Economics (Example Injection):** A concrete, numerical scenario demonstrating impact.
- **Technology & Tooling Stack:** Specific modern software tools used to manage this KPI.
- **Exit Readiness & Multiple Expansion:** How this metric impacts the exit multiple and buyer perception.

### 2. Content Density
- **Paragraphs:** Exactly 3 paragraphs per section.
- **Length:** Each paragraph must be 3-5 sentences long.
- **Injections:** Every article must include specific tool names (e.g., Coupa, NetSuite, Salesforce) and concrete math (e.g., "A 200 bps improvement in...").

### 3. Tone and Style
- **Voice:** Senior Operating Partner (Prescriptive, "We do this...", "In a typical LBO...").
- **Citations:** Zero external citations.
- **Language:** Professional, management-consulting style (e.g., "Value Creation Plan", "Operating Rhythm", "Alpha").
