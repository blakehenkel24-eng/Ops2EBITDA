# Operating Diagnostic Skills

This package contains uploadable `SKILL.md` files for PE operating workflows.

## Included Skills

- **Root Cause Hypothesis Builder** — Use when diagnosing performance gaps or KPI movement by creating specific, testable root cause hypotheses and validation steps.
- **Driver Tree Builder** — Use when breaking a KPI or business outcome into operating drivers, sub-drivers, data sources, owners, and actions.
- **Data Request Builder** — Use when creating specific data request lists needed to validate hypotheses, conduct operating analysis, or prepare diligence.
- **Variance Interpreter** — Use when interpreting budget-to-actual, period-over-period, or segment-level performance variances and their operating implications.
- **Issue Tree Builder** — Use when structuring messy operating problems into MECE issue trees for analysis, diligence, or workstream planning.
- **Next Analysis Recommender** — Use when deciding which analyses to run next after reviewing KPI movement, operating issues, diligence findings, or management commentary.
