# Value Creation Execution Skills

This package contains uploadable `SKILL.md` files for PE operating workflows.

## Included Skills

- **Initiative Charter Builder** — Use when turning a value creation idea or opportunity into a structured initiative charter with objective, scope, owner, KPI, milestones, and value logic.
- **30-60-100 Day Planner** — Use when converting priorities, diligence findings, or initiatives into phased 30/60/100-day execution plans.
- **Milestone Builder** — Use when breaking initiatives into practical weekly milestones, checkpoints, deliverables, and progress markers.
- **Benefits Tracker Designer** — Use when designing tracking logic for value creation benefits, including gross savings, implementation leakage, run-rate EBITDA, validation status, and owner accountability.
- **Recovery Plan Builder** — Use when an initiative, KPI, workstream, or integration milestone is off track and needs a corrective action plan.
- **Dependency Mapper** — Use when identifying dependencies, blockers, decision points, sequencing, and cross-functional coordination needs for value creation initiatives.
