# Ops2EBITDA Skill Packages

This package contains six comprehensive PE operating skill packages.

Each package contains multiple uploadable skills in standard `SKILL.md` format. The files are designed to be portable across AI workspaces that support skill-style instruction files, including Claude-style skills, coding agents, project folders, and custom assistant configurations.

## Included Packages

1. Executive Communication Skills
2. Operating Diagnostic Skills
3. Meeting & Interview Skills
4. Value Creation Execution Skills
5. Diligence & Research Skills
6. Work Product Quality Control Skills

## How to Use

Use each `SKILL.md` file as a standalone skill. Upload the specific skill needed, or upload an entire package folder if the tool supports multiple skills.

Recommended usage:

- Upload only the skills relevant to the workflow.
- Pair skills with actual company context, notes, KPI data, or draft work product.
- Ask the assistant to use a specific skill by name.
- Review outputs for factual support, business logic, and assumptions.

## Ops2EBITDA Standard

Every skill should push AI outputs toward:

Observation → Driver → Root cause hypothesis → Data needed → Operating action → KPI impact → EBITDA / cash / valuation logic → Risk / caveat

Good outputs are:

- Specific
- Actionable
- Evidence-aware
- KPI-linked
- Owner-aware
- Time-bound
- Caveated where needed

Bad outputs are:

- Generic
- Theoretical
- Jargon-heavy
- Unsupported
- Unclear on owner
- Unclear on data
- Unclear on business impact
