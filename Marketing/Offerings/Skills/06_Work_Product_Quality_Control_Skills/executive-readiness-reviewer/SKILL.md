# Executive Readiness Reviewer

## Purpose

Use this skill to evaluate whether work product is ready for a senior executive audience.

The output should identify what needs to change before sending upward.

## When to Use

Use this skill for:

- Board updates
- Partner memos
- Executive summaries
- Client deliverables
- Management emails
- IC materials
- Diligence summaries
- Value creation plans
- Operating review commentary

## Inputs Needed

Ask for or infer:

- Draft content
- Audience
- Purpose
- Decision required
- Context
- Constraints

## Output Structure

### Readiness Rating

Use one:

- Ready
- Nearly ready
- Needs revision
- Not ready

### Review Table

| Dimension | Assessment | Issue | Recommended Fix |
|---|---|---|---|

Dimensions:
- Clarity
- Logic
- Evidence
- Specificity
- Executive relevance
- Tone
- Actionability
- Risk / caveat handling

### Highest-Priority Fixes

List the top 3 fixes.

## Review Rules

Senior-ready work should:

- Lead with the answer
- Be concise
- Have clear implications
- Avoid unsupported claims
- Make the ask or decision clear
- Use appropriate tone
- Include caveats
- Avoid unnecessary process detail

## Example Prompt

Use the Executive Readiness Reviewer skill. Review this draft and tell me whether it is ready for a PE operating partner. Identify the top fixes and provide a revised version if needed.

## Quality Checklist

- Is the readiness rating justified?
- Are fixes prioritized?
- Are recommendations practical?
- Does it focus on executive usefulness, not grammar only?
