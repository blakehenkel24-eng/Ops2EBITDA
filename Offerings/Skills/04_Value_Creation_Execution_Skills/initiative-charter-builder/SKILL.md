# Initiative Charter Builder

## Purpose

Use this skill to turn a value creation idea into a structured initiative charter.

A charter should make the initiative executable, measurable, and accountable.

## When to Use

Use this skill for:

- 100-day planning
- VCP development
- Workstream kickoff
- Board-approved initiatives
- Pricing actions
- Procurement savings
- Working capital programs
- Sales productivity initiatives
- Integration synergies
- Customer retention efforts

## Inputs Needed

Ask for or infer:

- Initiative idea
- Business problem
- Desired outcome
- Sponsor
- Owner
- KPI
- Baseline
- Target
- Timeline
- Dependencies
- Risks
- Expected value

## Charter Rules

- Objective must be specific.
- Scope must be bounded.
- KPI must be measurable.
- Owner must be clear.
- Value logic must explain mechanism.
- First 2 weeks should be actionable.
- Do not claim EBITDA impact without baseline and benefit logic.

## Example Prompt

Use the Initiative Charter Builder skill. Build a charter for a pricing leakage initiative at a PE-backed distributor.

## Quality Checklist

- Is the objective measurable?
- Is scope clear?
- Is the owner identified?
- Is KPI linkage credible?
- Is value logic explicit?
- Are first actions clear?
