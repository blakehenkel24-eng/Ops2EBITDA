# Milestone Builder

## Purpose

Use this skill to break an initiative into practical milestones.

Milestones should create accountability and allow leadership to see whether execution is actually progressing.

## When to Use

Use this skill for:

- Value creation initiatives
- Integration workstreams
- Pricing actions
- Procurement savings
- Dashboard buildout
- Working capital programs
- Sales productivity programs
- Finance transformation
- Exit readiness workstreams

## Inputs Needed

Ask for or infer:

- Initiative objective
- Timeline
- Owner
- Key workstreams
- Dependencies
- Required outputs
- KPI target
- Current status

## Output Structure

| Week / Date | Milestone | Deliverable | Owner | Dependency | Proof Point | Status |
|---|---|---|---|---|---|---|

### Critical Path

Identify the milestones that cannot slip without affecting value capture.

### Leading Indicators

List early proof points that show whether the initiative is working.

## Milestone Rules

- Milestones should be observable.
- Avoid vague milestones like “continue analysis.”
- Each milestone should have a deliverable or proof point.
- Include dependencies.
- Include owners.
- Sequence logically.

## Example Prompt

Use the Milestone Builder skill. Build an 8-week milestone plan for a procurement savings initiative moving from spend cube to negotiated savings validation.

## Quality Checklist

- Are milestones specific?
- Are dates or weeks included?
- Are deliverables clear?
- Is the critical path identified?
- Are proof points measurable?
