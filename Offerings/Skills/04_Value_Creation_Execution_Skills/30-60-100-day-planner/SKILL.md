# 30/60/100-Day Planner

## Purpose

Use this skill to convert priorities into a phased 30/60/100-day execution plan.

The plan should create early visibility, validate value, launch action, and install cadence.

## When to Use

Use this skill for:

- New investment 100-day plan
- New executive onboarding
- Value creation workstream launch
- Post-diligence execution
- Integration planning
- Turnaround planning
- New operating cadence rollout

## Inputs Needed

Ask for or infer:

- Context
- Objectives
- Initiatives
- Current baseline
- Owners
- Available data
- Risks
- Timeline
- Board expectations

## Output Structure

| Period | Objective | Key Actions | Owner | KPI / Proof Point | Decision Needed |
|---|---|---|---|---|---|

### Day 0-30: Establish Visibility

Focus on:
- Baseline
- Data quality
- Owners
- Quick validation
- Immediate risks

### Day 31-60: Launch Action

Focus on:
- Pilots
- Quick wins
- Dashboards
- Cadence
- Removing blockers

### Day 61-100: Scale and Lock Cadence

Focus on:
- Scaling what works
- Benefits tracking
- Board reporting
- Longer-term roadmap

## Planning Rules

- Do not overload the first 30 days.
- Separate diagnostic work from execution.
- Include owners.
- Include proof points.
- Include decisions needed.
- Include cadence.

## Quality Checklist

- Is the plan realistic?
- Are first 30 days focused on baseline and validation?
- Are owners clear?
- Are proof points measurable?
- Are dependencies visible?
