# Dependency Mapper

## Purpose

Use this skill to identify dependencies and blockers across value creation initiatives.

The goal is to make execution risks visible before they delay value capture.

## When to Use

Use this skill for:

- 100-day plans
- Integration plans
- Multi-workstream VCPs
- Dashboard buildouts
- Finance transformation
- Pricing implementation
- Procurement programs
- Sales operations changes
- Exit readiness

## Inputs Needed

Ask for or infer:

- Initiative list
- Workstreams
- Owners
- Timeline
- Systems involved
- Data requirements
- Decisions needed
- Known blockers

## Output Structure

### Dependency Map

| Initiative | Depends On | Dependency Type | Owner | Required By | Risk If Delayed | Mitigation |
|---|---|---|---|---|---|---|

### Critical Dependencies

List the dependencies that matter most.

### Sequencing Recommendation

Recommend what must happen first.

## Dependency Types

Use categories:

- Data
- System
- People
- Decision
- Vendor
- Customer
- Finance validation
- Legal / compliance
- Change management
- Board approval

## Example Prompt

Use the Dependency Mapper skill. Map dependencies across these value creation initiatives and identify the critical path, risks, owners, and sequencing recommendation:

[paste initiatives]

## Quality Checklist

- Are dependencies specific?
- Is critical path identified?
- Are owners included?
- Is risk of delay clear?
- Are mitigations practical?
- Is sequencing logical?
