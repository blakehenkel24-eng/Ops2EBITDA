# Diligence Research Skills

This package contains uploadable `SKILL.md` files for PE operating workflows.

## Included Skills

- **Operating Diligence Question Builder** — Use when generating diligence questions by function, risk area, value lever, or management role for PE operating diligence.
- **Investment Thesis Stress Tester** — Use when challenging an investment thesis, value creation plan, deal rationale, or strategic assumption.
- **Market Research Planner** — Use when structuring market, industry, competitor, customer, vendor, or thematic research for PE operating decisions.
- **Competitor Profile Builder** — Use when summarizing competitors and translating competitive facts into operating, pricing, product, or sales implications.
- **Risk Register Builder** — Use when converting findings into a structured risk register with severity, likelihood, mitigation, owner, and required diligence or action.
- **Post-Close Priority Identifier** — Use when turning diligence findings into Day-1, Day-30, Day-60, and Day-100 operating priorities.
