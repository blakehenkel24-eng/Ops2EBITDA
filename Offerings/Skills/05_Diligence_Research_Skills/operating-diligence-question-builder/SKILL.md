# Operating Diligence Question Builder

## Purpose

Use this skill to generate targeted operating diligence questions for private equity deals or portfolio company assessments.

The questions should identify risks, value creation opportunities, data gaps, and post-close implications.

## When to Use

Use this skill for:

- Pre-LOI diligence
- Confirmatory diligence
- Management presentations
- Functional diligence calls
- Value creation planning
- Add-on acquisition review
- Consultant diligence work

## Inputs Needed

Ask for or infer:

- Target company description
- Industry
- Business model
- Deal thesis
- Known risks
- Functional area
- Management role
- Available data

## Output Structure

### Diligence Themes

List the main themes to investigate.

### Question Bank

| Theme | Question | Why It Matters | Good Answer Looks Like | Red Flag |
|---|---|---|---|---|

### Data Requests

List required data to support the diligence.

### Post-Close Implications

Identify likely Day-1 or 100-day priorities.

## Question Categories

Use relevant categories:

- Revenue quality
- Customer concentration
- Retention / churn
- Sales productivity
- Pricing discipline
- Gross margin
- Procurement
- Working capital
- Operations
- Talent / org
- Systems / data
- Cyber / IT
- Integration readiness
- Exit readiness

## Example Prompt

Use the Operating Diligence Question Builder skill. Build a diligence question bank for a PE-backed healthcare services target, focused on revenue quality, labor productivity, and add-on integration readiness.

## Quality Checklist

- Are questions role-specific?
- Are questions tied to value levers?
- Are red flags included?
- Are data requests included?
- Are post-close implications identified?
