# Executive Communication Skills

This package contains uploadable `SKILL.md` files for PE operating workflows.

## Included Skills

- **Board Update Writer** — Use when converting raw operating notes, KPI commentary, initiative status, or management updates into PE board-ready update language.
- **Executive Summary Builder** — Use when turning long notes, findings, or workstream materials into concise executive summaries for PE operating teams, boards, partners, or management.
- **Slide Bullet Sharpener** — Use when rewriting rough bullets into concise, consulting-style slide bullets with clear implications, parallel structure, and executive-ready phrasing.
- **So-What Generator** — Use when converting observations, data points, or findings into clear implications, actions, KPI impact, and value logic.
- **Status Update Writer** — Use when creating RAG status updates for initiatives, workstreams, PMO trackers, board updates, or management reviews.
- **Management Email Drafter** — Use when drafting direct, professional emails to management, executives, portco teams, advisors, or internal PE stakeholders.
