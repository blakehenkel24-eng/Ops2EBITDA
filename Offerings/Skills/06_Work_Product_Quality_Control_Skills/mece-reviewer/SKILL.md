# MECE Reviewer

## Purpose

Use this skill to review whether a structure is clean, non-overlapping, and complete enough for consulting or PE operating work.

MECE is a tool, not a religion. The goal is practical clarity.

## When to Use

Use this skill for:

- Issue trees
- Workstream structures
- Slide sections
- Initiative portfolios
- Diligence categories
- KPI driver trees
- Market maps
- Recommendation groups
- Root cause frameworks

## Inputs Needed

Ask for or infer:

- Current structure
- Purpose
- Audience
- Business context
- Desired level of detail

## Output Structure

### MECE Assessment

State whether the structure is:

- Clean
- Mostly clean
- Overlapping
- Missing major areas
- Too detailed / too shallow

### Review Table

| Category | Issue | Why It Matters | Recommended Fix |
|---|---|---|---|

### Revised Structure

Provide a cleaner version.

## Review Rules

Check for:

- Overlapping categories
- Missing categories
- Mixed levels of abstraction
- Symptoms mixed with root causes
- Actions mixed with outcomes
- Functions mixed with processes
- Too many branches
- Uneven granularity

## Example Prompt

Use the MECE Reviewer skill. Review this issue tree for overlap, missing branches, mixed levels, and clarity. Then provide a cleaner version:

[paste structure]

## Quality Checklist

- Are overlaps identified?
- Are missing areas identified?
- Is the revised structure practical?
- Is the structure aligned to the decision?
- Did it avoid overengineering?
