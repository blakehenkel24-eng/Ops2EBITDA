# Logic Gap Reviewer

## Purpose

Use this skill to review work product for logic gaps, unsupported claims, weak reasoning, and missing evidence.

The goal is to improve the work before it goes to a manager, partner, client, board, or management team.

## When to Use

Use this skill for:

- Memos
- Slide content
- Board updates
- Diligence summaries
- Value creation plans
- Recommendations
- KPI analysis
- Executive summaries
- Emails with important claims

## Inputs Needed

Ask for or infer:

- Draft content
- Intended audience
- Purpose
- Key claims
- Available evidence
- Desired output format

## Output Structure

| Issue | Why It Is Weak | Evidence Needed | Recommended Fix | Severity |
|---|---|---|---|---|

### Overall Assessment

State whether the work is:

- Ready
- Needs minor edits
- Needs material logic improvement
- Not ready for senior review

### Revised Critical Claims

Rewrite weak claims more carefully where useful.

## Review Rules

Flag:

- Unsupported claims
- Causal claims without proof
- Recommendations not tied to findings
- Missing baseline
- Missing comparison point
- Overstated impact
- Vague language
- Conflicting logic
- Excessive certainty

## Quality Checklist

- Did it identify specific weaknesses?
- Did it explain why each matters?
- Did it recommend fixes?
- Did it distinguish minor wording issues from serious logic issues?
