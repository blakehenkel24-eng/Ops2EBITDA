# Recommendation Sharpener

## Purpose

Use this skill to make recommendations sharper, more specific, and more actionable.

Weak recommendations often sound reasonable but cannot be executed. This skill fixes that.

## When to Use

Use this skill for:

- Executive summaries
- Board updates
- Diligence recommendations
- VCP initiatives
- Workstream plans
- Root cause analysis
- KPI diagnostics
- Management emails

## Inputs Needed

Ask for or infer:

- Current recommendation
- Context
- Evidence
- Objective
- Owner
- KPI
- Timeline
- Constraints

## Recommendation Rules

A strong recommendation includes:

- Specific action
- Owner or owner role
- Timing
- KPI or proof point
- Rationale
- Value logic
- Risk or caveat

Avoid:

- “Explore”
- “Consider”
- “Continue to monitor”
- “Optimize”
- “Improve”
- “Align”
- “Leverage”
unless followed by specific mechanism.

- Is the action specific?
- Is owner clear?
- Is timing included?
- Is KPI / proof point included?
- Is value logic credible?
- Is caveat included?
