# Work Product Quality Control Skills

This package contains uploadable `SKILL.md` files for PE operating workflows.

## Included Skills

- **Logic Gap Reviewer** — Use when reviewing analysis, memos, slides, recommendations, or executive summaries for unsupported claims, weak reasoning, and missing evidence.
- **MECE Reviewer** — Use when checking whether frameworks, issue trees, categories, recommendations, or slide structures are mutually exclusive and collectively exhaustive enough to be useful.
- **Executive Readiness Reviewer** — Use when determining whether a draft is ready for a partner, board, CEO, CFO, client, or investment committee audience.
- **Evidence Checker** — Use when reviewing claims for factual support, data gaps, caveats, assumptions, and overstatement risk.
- **Recommendation Sharpener** — Use when making recommendations more specific, actionable, owner-aware, KPI-linked, and executive-ready.
- **Tone Tightener** — Use when removing fluff, jargon, over-explanation, passive language, and generic consulting phrasing from PE operating work product.
