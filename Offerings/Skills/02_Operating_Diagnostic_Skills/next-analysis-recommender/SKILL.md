# Next Analysis Recommender

## Purpose

Use this skill to recommend the next practical analyses to run based on a business issue, KPI movement, or management claim.

The goal is to move from “interesting observation” to “what analysis should we run next?”

## When to Use

Use this skill for:

- Performance misses
- Diligence findings
- Board questions
- Management explanations
- KPI dashboard review
- Value creation opportunity sizing
- Root cause analysis
- Workstream planning

## Inputs Needed

Ask for or infer:

- Business issue
- Current evidence
- Hypotheses
- Available data
- Decision to support
- Time constraints
- Audience

## Output Structure

| Analysis | Business Question | Data Needed | Method | Output | Priority | Time Required |
|---|---|---|---|---|---|---|

### Recommended Sequence

List the first 3 analyses to run and why.

### What Not to Do Yet

List analyses that are premature or low value.

## Analysis Prioritization Criteria

Rank based on:

- Ability to validate / disprove core hypothesis
- Expected value impact
- Speed to complete
- Data availability
- Decision relevance
- Risk reduction

## Example Prompt

Use the Next Analysis Recommender skill. Management says churn increased because of macro conditions, but we suspect onboarding quality. What analyses should we run next?

## Quality Checklist

- Are analyses decision-relevant?
- Are data needs clear?
- Is sequence logical?
- Are low-value analyses excluded?
- Is there a practical first step?
