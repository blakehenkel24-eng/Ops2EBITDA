# Ops2EBITDA Skill Packages — Store Catalog

## Packages

### Executive Communication Skills

- **Board Update Writer** — Use when converting raw operating notes, KPI commentary, initiative status, or management updates into PE board-ready update language.
- **Executive Summary Builder** — Use when turning long notes, findings, or workstream materials into concise executive summaries for PE operating teams, boards, partners, or management.
- **Slide Bullet Sharpener** — Use when rewriting rough bullets into concise, consulting-style slide bullets with clear implications, parallel structure, and executive-ready phrasing.
- **So-What Generator** — Use when converting observations, data points, or findings into clear implications, actions, KPI impact, and value logic.
- **Status Update Writer** — Use when creating RAG status updates for initiatives, workstreams, PMO trackers, board updates, or management reviews.
- **Management Email Drafter** — Use when drafting direct, professional emails to management, executives, portco teams, advisors, or internal PE stakeholders.

### Operating Diagnostic Skills

- **Root Cause Hypothesis Builder** — Use when diagnosing performance gaps or KPI movement by creating specific, testable root cause hypotheses and validation steps.
- **Driver Tree Builder** — Use when breaking a KPI or business outcome into operating drivers, sub-drivers, data sources, owners, and actions.
- **Data Request Builder** — Use when creating specific data request lists needed to validate hypotheses, conduct operating analysis, or prepare diligence.
- **Variance Interpreter** — Use when interpreting budget-to-actual, period-over-period, or segment-level performance variances and their operating implications.
- **Issue Tree Builder** — Use when structuring messy operating problems into MECE issue trees for analysis, diligence, or workstream planning.
- **Next Analysis Recommender** — Use when deciding which analyses to run next after reviewing KPI movement, operating issues, diligence findings, or management commentary.

### Meeting Interview Skills

- **Management Interview Guide Builder** — Use when preparing structured interview guides for CEO, CFO, CRO, COO, functional leaders, portco management, or diligence calls.
- **Meeting Agenda Builder** — Use when creating crisp meeting agendas with objectives, topics, decisions needed, timing, and expected outputs.
- **Follow-Up Tracker Builder** — Use when converting meeting notes, calls, workstream updates, or diligence conversations into action trackers with owners and due dates.
- **Evasive Answer Detector** — Use when reviewing management responses, interview notes, or update commentary to identify vague, unsupported, evasive, or contradictory answers.
- **Decision Log Writer** — Use when documenting decisions made, rationale, owners, implications, open questions, and next steps from meetings or workstreams.
- **Pre-Read Summarizer** — Use when summarizing meeting pre-reads, board materials, management updates, or reports into what matters, questions, and decisions.

### Value Creation Execution Skills

- **Initiative Charter Builder** — Use when turning a value creation idea or opportunity into a structured initiative charter with objective, scope, owner, KPI, milestones, and value logic.
- **30-60-100 Day Planner** — Use when converting priorities, diligence findings, or initiatives into phased 30/60/100-day execution plans.
- **Milestone Builder** — Use when breaking initiatives into practical weekly milestones, checkpoints, deliverables, and progress markers.
- **Benefits Tracker Designer** — Use when designing tracking logic for value creation benefits, including gross savings, implementation leakage, run-rate EBITDA, validation status, and owner accountability.
- **Recovery Plan Builder** — Use when an initiative, KPI, workstream, or integration milestone is off track and needs a corrective action plan.
- **Dependency Mapper** — Use when identifying dependencies, blockers, decision points, sequencing, and cross-functional coordination needs for value creation initiatives.

### Diligence Research Skills

- **Operating Diligence Question Builder** — Use when generating diligence questions by function, risk area, value lever, or management role for PE operating diligence.
- **Investment Thesis Stress Tester** — Use when challenging an investment thesis, value creation plan, deal rationale, or strategic assumption.
- **Market Research Planner** — Use when structuring market, industry, competitor, customer, vendor, or thematic research for PE operating decisions.
- **Competitor Profile Builder** — Use when summarizing competitors and translating competitive facts into operating, pricing, product, or sales implications.
- **Risk Register Builder** — Use when converting findings into a structured risk register with severity, likelihood, mitigation, owner, and required diligence or action.
- **Post-Close Priority Identifier** — Use when turning diligence findings into Day-1, Day-30, Day-60, and Day-100 operating priorities.

### Work Product Quality Control Skills

- **Logic Gap Reviewer** — Use when reviewing analysis, memos, slides, recommendations, or executive summaries for unsupported claims, weak reasoning, and missing evidence.
- **MECE Reviewer** — Use when checking whether frameworks, issue trees, categories, recommendations, or slide structures are mutually exclusive and collectively exhaustive enough to be useful.
- **Executive Readiness Reviewer** — Use when determining whether a draft is ready for a partner, board, CEO, CFO, client, or investment committee audience.
- **Evidence Checker** — Use when reviewing claims for factual support, data gaps, caveats, assumptions, and overstatement risk.
- **Recommendation Sharpener** — Use when making recommendations more specific, actionable, owner-aware, KPI-linked, and executive-ready.
- **Tone Tightener** — Use when removing fluff, jargon, over-explanation, passive language, and generic consulting phrasing from PE operating work product.
